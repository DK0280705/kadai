\subsection{問題(1): Ex.2-1~2.4}\label{subsec:exercise2}

教材の例題に従い、$3 \times 3 \times 3$ の立方体における電球の配置を3階テン
ソルで表現し、\texttt{modeSum} 関数を用いて3方向からの透視図を作成する。
電球の位置は $\{1,5,9,11,15,16,21,22,26\}$ である。
\newpage
% ============================================================
\subsubsection{3階テンソルの生成}

\textbf{スクリプト}

\begin{lstlisting}[language=R]
library(rTensor)
A <- array(0, dim = c(3,3,3))
A[1,1,1] <- A[2,2,1] <- A[3,3,1] <- 1
A[2,1,2] <- A[3,2,2] <- A[1,3,2] <- 1
A[3,1,3] <- A[1,2,3] <- A[2,3,3] <- 1
A <- as.tensor(A)
\end{lstlisting}

\textbf{説明}
$3\times3\times3$ の立方体を表す配列を作り、電球がセットされた
位置（1,5,9,11,15,16,21,22,26）に1を代入し、\texttt{as.tensor} で
rTensor オブジェクトに変換する。

\textbf{結果}

% ============================================================
\subsubsection{透視図の作成 (modeSum)}

\textbf{スクリプト}

\begin{lstlisting}[language=R]
A_1sum <- modeSum(A, 1, drop=TRUE)
A_2sum <- modeSum(A, 2, drop=TRUE)
A_3sum <- modeSum(A, 3, drop=TRUE)
\end{lstlisting}

\textbf{説明}

\texttt{modeSum(tnsr, m, drop)} は、テンソル \texttt{tnsr} の $m$-モードに
沿って部分テンソルの和をとる関数である。\texttt{drop=TRUE} を指定すると、
和をとったモードが削除され、1階低いテンソル（ここでは行列）が得られる。

\begin{itemize}
  \item \texttt{modeSum(A, 1, drop=TRUE)}：上から下方向に見た透視図。
    モード1（$i_1$）方向に和をとることで、$i_2$-$i_3$ 平面の $3 \times 3$ 行列が得られる。
  \item \texttt{modeSum(A, 2, drop=TRUE)}：左から右方向に見た透視図。
    モード2（$i_2$）方向に和をとることで、$i_1$-$i_3$ 平面の $3 \times 3$ 行列が得られる。
  \item \texttt{modeSum(A, 3, drop=TRUE)}：前から後方向に見た透視図。
    モード3（$i_3$）方向に和をとることで、$i_1$-$i_2$ 平面の $3 \times 3$ 行列が得られる。
\end{itemize}

% ============================================================
\subsubsection{透視図の確認と点灯判定}

\textbf{結果}

\begin{lstlisting}[language=R]
> A_1sum
Numeric Tensor of 2 Modes
Modes:  3 3
Data:
     [,1] [,2] [,3]
[1,]    1    1    1
[2,]    1    1    1
[3,]    1    1    1
> A_2sum
Numeric Tensor of 2 Modes
Modes:  3 3
Data:
     [,1] [,2] [,3]
[1,]    1    1    1
[2,]    1    1    1
[3,]    1    1    1
> A_3sum
Numeric Tensor of 2 Modes
Modes:  3 3
Data:
     [,1] [,2] [,3]
[1,]    1    1    1
[2,]    1    1    1
[3,]    1    1    1
\end{lstlisting}

\textbf{説明}

3方向すべての透視図において、すべての要素が1となっている。これは、どの方向から
見てもすべての位置で電球が点灯して見えることを意味する。例題の電球配置
$\{1,5,9,11,15,16,21,22,26\}$ は、各方向から見て影になるマスが1つもない
全点灯の配置であることが確認できた。

\subsection{問題2(a): $n$-モード行列展開の手動実装}\label{subsec:2-a}

\subsubsection{実装}

演習IIIのスライド5の定義に従って、3階テンソルの $n$-モード行列展開をRで手動
実装する。出席番号 4347 に基づき \texttt{set.seed(5347)} でテンソルを生成し、
手動実装と \texttt{unfold} 関数の結果を比較する。

\lstinputlisting[language=R, caption=問題2(a)のRスクリプト, label=lst:p2a]
{code/problem2a.R}

\subsubsection{結果}

\begin{lstlisting}
1-mode match: TRUE 
2-mode match: TRUE 
3-mode match: TRUE
\end{lstlisting}

手動実装（定義に従う）と \texttt{unfold} 関数の結果は、すべてのモードで完全
に一致した。

\subsubsection{説明}

手動実装では、定義に従って3重ループを用いて各要素を適切な行・列に配置した。
\texttt{unfold} 関数は \texttt{col\_idx} で指定されたモードの順序に従って
列を並べる。手動実装と \texttt{unfold} 関数の結果を一致させるには、定義と
同じ列順序になるように \texttt{col\_idx} を指定する必要がある。

1-モードの場合、定義では列インデックスが $(i_3-1)I_2 + i_2$ であり、これは
\texttt{col\_idx=c(2,3)}（モード2が最も速く変化）に対応する。演習IIIの例
（\texttt{col\_idx=c(3,2)}）では列の並び順が異なるが、含まれる要素の集合は
同一である。

3-mode sum では各 $(i_1,i_2)$ に必ず1個以上の電球が存在し、全方向全点灯となる。

\section{感想}\label{sec:reflection}

て理解を深めることができた。特に、3階テンソルを立方体に対応させ、電球の点灯の
ような具体的な例を通して学ぶことで、抽象的なテンソル操作を直感的に理解すること
ができた。
